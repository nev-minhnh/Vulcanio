**Vulcanio 1.3.0 — The all-in-one studio** · Windows 11 x64

- `Vulcanio-1.3.0-windows-x64.zip`: unzip and run `vulcanio.exe` (no installation needed).
- `Vulcanio-Setup-1.3.0.exe`: installer; adds Vulcanio to "Open with" for the file types it opens.

### 1.3.0
- **Every app starts on its own start page.** No more blank documents or last session's work when an app opens: Photo and Vector show their home screens, Interface shows Home without making a new file, CAD shows its Start page instead of a blank drawing, and Library starts on its library chooser. Opening a file still goes straight to it.
- **New Settings.** A sidebar of pages (General, Appearance, Motion, Files, Performance, About), cards of options with switches, segmented choices and theme previews, a short explanation under every option, and changes that apply at once. About is now a page of Settings, with a button to open the log folder.

### 1.2.2
- Faster first start after boot: DirectX 12 only, the GPU Windows chooses, and Startup boost.
