**Vulcanio 1.2.2 — The all-in-one studio** · Windows 11 x64

- `Vulcanio-1.2.2-windows-x64.zip`: unzip and run `vulcanio.exe` (no installation needed).
- `Vulcanio-Setup-1.2.2.exe`: installer; adds Vulcanio to "Open with" for the file types it opens.

### 1.2.2 — faster first start after boot
- DirectX 12 only on Windows: the Vulkan and OpenGL drivers are no longer loaded at every start (they are tried only if DirectX 12 can't start).
- Uses the GPU Windows chooses for Vulcanio instead of always waking a discrete GPU.
- **Startup boost** (like Microsoft Edge): shortly after you sign in to Windows, a low-priority background run reads Vulcanio and loads the graphics driver, then exits. On by default; Settings › Startup.
- The log (`%APPDATA%\Vulcanio\data\logs\vulcanio.log`) records the time to the first frame.

### 1.2.1
- Fixed: the window went black when Vulcanio Photo opened a file on a real GPU.
- Graphics errors and crashes are written to the log.
